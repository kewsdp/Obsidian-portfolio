- **Float** values used to represent any important data about the owning object.
- Feature *"ValueChangeDelegates"*, that can be hooked up to other functions, an example being UI updates.
- Another form are **"Meta Attributes"**, that aren't saved between effects, making them useful for acting as temporary values for calculation classes e.g. Damage value, different for each weapon and mitigated by armor and health buffs
